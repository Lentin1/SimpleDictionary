# 简辞桌面版重构说明

新版桌面端使用 Tauri 2 + React + TypeScript + SQLite，目标平台是 Apple Silicon macOS。旧 Electron/Vinext 入口暂时保留，方便在迁移期间回退和对照；正式桌面开发入口使用 v2/ 与 src-tauri/。

## 数据与迁移

- 数据库位于 `~/Library/Application Support/com.vocabflow.jianci/jian-ci.sqlite3`。
- 首次启动时会读取旧版 ~/Library/Application Support/vocab-flow/simple-dictionary-state.json，迁移词书、词条、进度、章节计划、学习历史和未完成会话。
- 词书内容、学习进度、备份和 SQLite 数据都不会写入 Git，也不会打进 DMG。
- 每次切换词书、导入、修改章节计划或回答单词后，SQLite 会记录本地快照。
- AI 接口地址、模型和 AI 发音设置保存到 SQLite；API Key 只写入 macOS 钥匙串，AI 发音与 AI 助教共用同一个 Key。
- JSON 备份会导出词书、进度、计划、历史记录、生词和未完成的生词复习会话；当前 Tauri 界面只有导出入口，没有恢复入口。

## 常用命令

~~~bash
npm run v2:typecheck
npm run v2:build
PATH=/opt/homebrew/opt/rust/bin:$PATH cargo test --manifest-path src-tauri/Cargo.toml
PATH=/opt/homebrew/opt/rust/bin:$PATH cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
npm run lint
npm test
git diff --check
npm run tauri:dev
~~~

v2/ 是 Tauri 桌面应用的前端源码，不作为独立 Web 产品发布。`v2:dev` 只是 `tauri:dev` 调用的内部 Vite 开发服务器，日常使用 `npm run tauri:dev` 启动完整桌面应用。DMG 构建由 tauri:build 负责；发布前再运行完整回归并人工检查迁移数据。词书不会被预置到应用包内，用户首次使用时从本地导入。

`app/pronunciation-demo/` 与 `app/api/pronunciation-demo/route.ts` 是隔离的旧 Web/Sites 发音试听工具，不是 Tauri 桌面端运行路径。代理只允许 TokenDance 与 MiniMax 官方 HTTPS 端点，并拒绝跨主机重定向；Web 试听页的发布状态不能代表桌面应用或 DMG 已更新。

## 学习队列与界面

学习和复习都按所选任务日期的章节取词；日历中任意过去日期都可以补做学习、复习和打卡。已经在该日期答对的词不会因切换日期而重新进入队列；当天目标数以首次记录的目标为基准，不会随着已掌握状态缩小。选择“不认识”后，单词进入当前队列尾部，必须再次答对才会从本轮移除。选择后按 Z 可以撤销本次选择，Space 进入下一个单词。未来日期不提供提前预习入口。

左侧“生词本”只显示当前词书中手动收藏的单词，并显示数量。学习卡和当前词书预览都可以收藏或取消收藏；认识或不认识不会自动改变生词成员资格。生词本按最近加入排序，可搜索、按章节筛选、发音和单条移除。

生词专项复习会随机生成独立队列，未完成时再次进入会继续原队列，完成后再开始才会重新打乱。专项复习沿用认识、不认识、队尾重试、撤销、自动发音和 AI 问答。答题会更新普通掌握状态，但不计入每日目标、历史计数或打卡；单词仍保留在生词本中，直到手动移除。

左侧导航固定在窗口顶部，不随主内容滚动。“设置”页集中管理外观、答题后发音、MiniMax AI 发音和 AI 接口；通过 TokenDance 时，AI 发音默认使用模型 ID `minimax-speech-2.8-turbo` 与 `English_PlayfulGirl`，可切换 AI 优先或现有语音优先，外观可选择跟随系统、浅色或深色，跟随系统时会响应 macOS 外观变化。

界面采用 macOS Liquid Glass 风格，并参考 Safari 的窗口结构：侧栏贴合窗口左侧、按学习/词汇/偏好分组，顶部面板按钮可随时折叠或展开。玻璃材质只用于侧栏和浮层，学习内容、设置内容与普通控件使用高可读性的标准材质；常规信息页保持紧凑，学习页则让当前单词成为单一视觉重点。配色由 `#0f172a` 与 `#1e293b` 承载背景和内容层级，`#38bdf8` 用于主操作、选中和完成状态，`#c084fc` 用于复习、不认识和 AI 辅助状态，`#f472b6` 仅用于删除与错误反馈；浅色外观使用同一配色的对比度安全派生色。窗口缩窄到桌面最小尺寸时侧栏会自动压缩为图标模式，双栏内容改为单栏。

AI 面板使用独立消息滚动区，新消息会平滑定位到最新位置；提供“怎么记忆”“怎么用”“派生词”“词根”四个一键问题。中文输入法组词期间的 Enter 只确认输入，组词结束后再次按 Enter 才发送问题。

“我的词书”中的“AI 校对”会在右下角悬浮窗中把当前词书分批发送到已配置的 AI 接口，后台显示实时进度，不阻塞主界面。每批完成后会把断点和已发现问题保存到 SQLite；网络波动或 AI 返回异常时最多自动尝试 3 次，仍失败则停止请求并允许用户手动从断点继续。应用重启后再次校对会从已完成批次继续，词书内容变化时会自动重新开始。配置错误、权限错误或接口地址不合法等不可重试错误会保留在悬浮窗中提示。它会检查明显拼写或符号错误、词性与词义不匹配，以及单词和词义完全不符的词条。AI 只生成待审建议，不会直接改动词书；用户可以逐项检查、取消勾选后，再确认应用。应用时保留单词标识和已有学习进度，并为本次修改建立本地快照。

“设置”页的“快捷键”可以修改不认识、认识、下一个、撤销、发音和打开 AI 六个学习操作，支持单键及 ⌘、⌥、⇧、⌃ 组合键。快捷键只保存在本机；重复绑定会被拒绝，点击“恢复默认”可回到 ←、→、Space、Z、P、A。

多词性释义优先从完整原始释义拆分；拆分结果无法覆盖全部原文时会回退到完整释义。TXT 例句会保存到 SQLite 并传入 AI 上下文，但当前 Tauri 学习卡尚未显示独立例句区域。单词发音可按设置优先使用 MiniMax T2A 的 `English_PlayfulGirl`，失败时直接回退到 macOS 的 Samantha 或其他可用英语音色；关闭 AI 发音或选择现有语音优先时不会请求第三方词典发音服务。
